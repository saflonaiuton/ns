↓DIRECT MEDIA TOOL

Download a media file

Enter a direct link to a video or audio file. This tool does not extract media from social post pages.

Use a direct HTTP(S) link that returns a video or audio file—not a Facebook, Instagram, TikTok, or other social post link.

For safety, the server blocks private/local network addresses, follows only a few validated redirects, and limits files to 512 MiB.

Downloads are streamed through this server. Do not submit private links, login-protected media, or content you are not authorized to save.

This project is independent and not affiliated with any social-media platform.
